# 📚 BookVibes - Full Stack Web Application

A full-stack book catalog and discovery web application built with **React.js** on the frontend and **ASP.NET Core Web API (.NET C#)** on the backend, using **MySQL** for data storage[cite: 1].

## 🚀 Tech Stack

* **Frontend:** React.js, JavaScript, HTML, CSS
* **Backend:** ASP.NET Core Web API (C#)
* **Database:** MySQL

---

## 🛠️ Features

* Browse and search through a comprehensive catalog of books.
* Discover book details, reviews, and recommendations.
* Seamless communication between React frontend and .NET backend API.
